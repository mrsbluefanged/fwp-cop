# FWP Community of Practice — Learn Better, Together

A simple, mobile-friendly three-task learning activity for Family Welfare Programme (FWP) practitioners.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository, e.g. `fwp-cop-journey`.
2. Select **Add file → Upload files** and upload `index.html` and `.nojekyll` (or use the individual `index.html` file; `.nojekyll` is optional). Commit them to the `main` branch.
3. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**. Select branch **main** and folder **/(root)**, then **Save**.
4. Wait for Pages to publish and open the URL shown in Settings → Pages, commonly `https://YOUR-USERNAME.github.io/fwp-cop-journey/`.
5. Test on a mobile phone, including the checkboxes, notes, Back/Next navigation, and Print My Key Takeaways.

## Notes

- No backend or sign-in is needed.
- Participant answers are stored only in each device's browser local storage; they are **not** submitted or collected by GitHub.
- Printing uses the phone or desktop browser's print/share options.
- The site will be publicly viewable if the repository and Pages site are public. Do not include confidential participant information in the source files.
- If you update the app, replace `index.html` in the repository and commit the change.

## Files

- `index.html`: Entire app, self-contained with its styles and scripts.
- `.nojekyll`: Small GitHub Pages configuration marker.
